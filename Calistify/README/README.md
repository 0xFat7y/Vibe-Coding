## 🎯 About The Project

**CALISTIFY** is a state-of-the-art calisthenics training platform that revolutionizes how people approach bodyweight fitness. Inspired by professional platforms like Gornation, but with enhanced educational focus, superior organization, and cutting-edge web technologies.

### ✨ What Makes Calistify Special?

| Feature | Description |
|---------|-------------|
| 🎓 **Educational-First** | Comprehensive progression from absolute beginner to elite athlete |
| 💪 **400+ Exercises** | Detailed library across 4 progressive training levels |
| 🍎 **Nutrition System** | Complete dietary guidance for optimal performance |
| 🛒 **E-commerce Ready** | Integrated shop for training equipment |
| 📊 **Progress Tracking** | Track workouts, earn badges, monitor improvement |
| 🎨 **Ultra-Modern UI** | Dark theme with fire/gold aesthetic and advanced animations |
| 📱 **Fully Responsive** | Perfect experience on any device |
| ⚡ **Zero Dependencies** | Pure HTML/CSS/JS - blazing fast performance |

## 🚀 Getting Started

### **Prerequisites**

- Modern web browser (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
- Text editor (VS Code recommended)
- Basic knowledge of HTML/CSS/JS (for customization only)

### **Installation**

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/calistify.git

# 2. Navigate to project directory
cd calistify

# 3. Open in browser
open index.html
# or simply double-click index.html
```

### **Optional: Local Server**

```bash
# Python 3
python -m http.server 8000

# Node.js (with http-server)
npx http-server -p 8000

# PHP
php -S localhost:8000
```

Then visit: `http://localhost:8000`

### **For End Users**

1. **Explore Training Levels**
   - Navigate to "Training" in the menu

   - Browse exercises and programs

2. **Create Account & Track Progress**

   - Visit the Shop page
   - Add items to cart
   - Proceed to checkout (demo)

4. **Learn About Nutrition**
   - Read macro guidelines
   - Explore diet approaches
   - Get practical tips

### **For Developers**

#### **Add Exercise GIFs**
```bash
# 1. Save GIFs to images/exercises/
mkdir -p images/exercises
# Add your GIFs: push-up.gif, pull-up.gif, etc.

# 2. Update HTML
<!-- Replace emoji placeholder in exercise cards -->
<div class="exercise-image">

</div>
```

```css

```

## 🎨 Customization

### **Color Themes**

Edit `css/styles.css`:
```css
:root {
  /* Primary Colors */
  --primary: #FF4D00;           /* Fire orange */
  --primary-dark: #CC3D00;
  --primary-light: #FF7733;
  
  /* Accent Colors */
  --accent: #FFD700;            /* Gold */
  --accent-light: #FFED4E;
  
  /* Neon Effects */
  --neon-blue: #00F0FF;
  --neon-pink: #FF006E;
  --neon-green: #00FF88;
  
  /* Backgrounds */
  --bg-primary: #000000;
  --bg-secondary: #0A0A0A;
  --bg-card: #1A1A1A;
}
```

### **Typography**

```css
:root {
  --font-display: 'Bebas Neue', cursive;    /* Large titles */
  --font-heading: 'Rajdhani', sans-serif;   /* Headings */
  --font-body: 'Outfit', sans-serif;        /* Body text */
}
```

### **Animations**

```css
/* Disable specific animations */
.floating {
  animation: none; /* Disable floating */
}

/* Adjust speed */
.rainbow-border::before {
  animation: rainbowRotate 2s linear infinite; /* Faster */
}
```

### **Add Custom Badges**

Edit `js/main.js`:
```javascript
const badges = [
  { name: 'First Steps', requirement: 5 },
  { name: 'Getting Strong', requirement: 20 },
  { name: 'Dedicated Athlete', requirement: 50 },
  { name: 'Calisthenics Master', requirement: 100 },
  { name: 'Your Custom Badge', requirement: 200 } // Add here
];
```
